# Сверка технического задания и свойств ортофото

Пример выделяет шесть кандидатов требований из конкретного PDF и сверяет применимые требования со свойствами GeoTIFF. Результат можно посмотреть в [отчёте](rezultaty-vinograd/report.md). В [JSON](rezultaty-vinograd/report.json) указаны страницы ТЗ, свойства файла, результаты проверок и контрольные суммы.

Проверены формат, система координат и чтение девяти участков изображения. Размер пикселя в градусах оставлен на ручную проверку по требованию в сантиметрах. Геодезическая точность этим способом не определяется.

Для повтора на Python 3.12:
```sh
python -m pip install -r requirements.txt
python download_inputs.py
python proverka_vinograd.py
```

Внешние файлы загружаются по ссылкам в отчёте с проверкой SHA-256. Образец ортофото — Santiago Pastor, OpenAerialMap / Open Imagery Network, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Это независимый образец для сверки свойств. Техническое задание получено с сайта Союза виноградарей и виноделов России.
