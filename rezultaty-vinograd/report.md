# Проверка открытого GeoTIFF по ТЗ виноградарей

Кандидаты правил извлечены из текстового PDF. Специалист ещё не подтвердил чек-лист. Это демонстрация проверки свойств, не приёмка заказа.

| Проверка | Статус | Пояснение |
|---|---|---|
| format | pass | GTiff + CRS |
| crs | pass | EPSG:4326; target WGS-84 / EPSG:4326 |
| pixel_visible | manual | Пиксель в градусах: прямое сравнение с 0.05 м запрещено |
| channels_spectral | not_applicable | Образец назначен видимому ортофото, правило пяти каналов относится к спектрозональному |
| plan_accuracy | manual | Нужны контрольные точки и специалист; заголовок TIFF не подтверждает СКО |

Растр: 32768 × 28672, каналов 3, EPSG:4326. Размер пикселя [1.8570532226563907e-07, 1.857038225097803e-07] degree.
Прочитано девять окон 32×32, полная декодировка всех пикселей не проверялась.
В демонстрационной папке отсутствуют остальные восемь позиций сдачи. Это не недостатки реального подрядчика: образец не относится к этому ТЗ.
